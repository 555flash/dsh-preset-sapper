# 研判 — 先判"这是什么"，再判"能不能打"

打错方向的成本比打不动高得多：把一个仿冒站当正主打，结论全废；把一个正常业务当黑产，要吃官司。
**研判卡是开工的第一张图，不是收尾的第一段话。**

## 一、研判卡（新目标 10 分钟内出）

```
目标：<域名/IP/APP/账号>
形态：正版 / 仿冒 / 盗版 / 灰产 / 黑产 / 不明
依据：<3–5 条，每条带来源与时间>
诈骗类型：<杀猪盘/刷单/虚假投资/假客服/游戏交易/裸聊敲诈/赌诈/贷款/其他/不适用>
基础设施：注册商/NS/托管 ASN/证书签发者/同 IP 资产数
活跃度：最近一次更新/cert 签发时间/群活跃时间
风险：<打下去会不会踩到第三方，是否涉及真实用户数据>
建议：继续 / 只做只读对照 / 停手并上报
```

判不准就写 `不明`，按**白**处理：只做只读对照（DNS/证书/公开页面），不做主动扫描。

## 二、形态判据（按可靠性排序）

**强证据（能单独支撑结论）**
- 域名注册时间极短（< 60 天）+ 模板化页面 + 无备案 → 高度疑似仿冒/临时站。
- 证书与品牌方证书链无关，且 CN/SAN 指向仿冒域名 → 仿冒。
- 页面内嵌的联系方式/收款账号与官方不一致 → 仿冒/诈骗。
- 客服通道指向 TG/QQ 个人号而非官方工单 → 黑产特征。
- 同一个模板出现在 ≥3 个不同域名（favicon hash / 静态资源 hash 相同）→ 团伙批量投放。

**中等证据（需要交叉）**
- 托管在廉价 ASN / 高滥用机房（先看 `ip_geo_lookup` 的 ASN 与代理标记）。
- 使用免费 CDN + 隐藏源站。
- 页面语言/时区/货币与宣称的服务地区不符。

**弱证据（不能单独用）**
- "看起来很像" / 页面美术风格类似。
- 同一个 ASN / 同一个 CDN。
- 域名里有相同品牌词。

> **FALSE_MERGE 警告**：仅凭「同品牌词 + 同 ASN + 同模板」就把两个目标判成同一团伙，是最常见的误判。仿冒者之间会互相抄模板，也会共用同一个建站服务商。

## 三、备案与主体核验

```
web_search("<域名> 备案")            # 公开备案查询入口
web_fetch("https://icp.chinaz.com/<域名>")  # 或任一公开 ICP 查询页
```
核验三件事：**主体名是否与宣称一致**、**备案号是否能反查到该域名**、**主体是否已被列入异常**。
- 有备案但主体名对不上 → 大概率是盗用备案号。
- 完全无备案却做境内金融/医疗/教育业务 → 违规面，可作为举报依据（但不是"能打"的依据）。

## 四、归因分级（报告里必须标级）

| 级别 | 定义 | 需要什么 |
|---|---|---|
| **HARD** | 同一实体 | ≥2 个**独立**源指向同一唯一标识（同一机器码 / 同一收款地址 / 同一绑定手机号 / 同一后台账号），且互相不派生 |
| **SOFT** | 单一指向 | 只有一条线索（同一个群、同一次注册、同一个 ASN） |
| **FALSE_MERGE** | 判错了 | 仅品牌/ASN/模板相同就合并——必须显式撤回 |
| **UNKNOWN** | 未验证 | 没查或查不到，写清楚没查什么 |

**独立源的定义**：两源的数据如果都来自同一次泄露/同一个采集，它们不算两个源。写字的时候要能回答"这两条如果不是同一个人，为什么还会同时出现"。

## 五、从情报到结论的三步

1. **要素收敛**：把 IP、域名、手机号、TG/QQ/微信、银行卡、机器码、文件 MD5 列成表，每个要素标注来源。
2. **交叉命中**：找出「被 ≥2 个要素共同指向」的节点。这里用 `sapper-sensors` 的拼图套路：IP → 机器码 → 身份；手机号 → TG → 群 → 同群成员。
3. **反向验证**：对最强的那个结论，主动找**反证**——这个手机号有没有可能只是接码平台的？这台机器是不是网吧/云手机？找不到反证才升级到 HARD。

## 六、入图形态

研判结论本身也是一条事实，别只写在对话里：

```
sapper_write action=fact kind=note
  text="<目标> 判定为仿冒站：注册 12 天、模板与官网无关、客服指向 TG 个人号"
  title="研判：仿冒"
  data=["verdict=impostor","confidence=HARD","sources=3","first_seen=2026-11-20"]
```

归因关系用 `note` + `data` 表达，**不要**把两个目标合成一个 fact：

```
data=["relation=same-actor","grade=SOFT","via=phone:+86***","counter=同群不同人待排除"]
```

## 七、红线

- **不做人肉**：不查与案件无关的自然人信息；`dting_unlock` 这类高敏感动作只在必要时用，结论写最小断言。
- **不接触目标**：不私聊、不加群、不点链接、不充值试探。
- **不越权取证**：只取公开面与授权数据源；不碰对方后台（除非范围明确允许）。
- **不确定就写不确定**：报告里出现 `HARD` 必须有两条独立源；没有就写 `SOFT`。
